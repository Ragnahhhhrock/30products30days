# DayBadge
The brand's "30" sticker with the day number swapped in (07, 12, 30) and the Flamingo spark. It is each product's icon.

- Render at 32px or larger. Below that use the small-size mark in `assets/Logos`.
- Keep clear space of half the badge width. The hard shadow always falls bottom-right.
- The badge fill stays Launch yellow in both themes; digits are Midnight.
