# ProductCard
The product listing: Flamingo header with the day and product type, then title, one sentence, price and a Button. 360px wide by default, with the `shadow-hard-md` offset.

- One sentence of description, plain words, no hype.
- Price is a real price or "Free". The consumer provides day, title, description, price and link.
- Stack cards in a grid with at least `space-4` (24px) gap so shadows do not touch.
